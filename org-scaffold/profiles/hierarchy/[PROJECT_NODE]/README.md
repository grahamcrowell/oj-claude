# [PROJECT_NODE]

An example project node. Rename the directory to the project it owns, and
delete the typed files it does not need — a node is not required to carry all
four.

## The four typed files

Each maps to a `resolve-path` category key. A skill asks for the key and the
node; it never hardcodes a path.

| File | Key | Answers |
|------|-----|---------|
| `requirements.md` | `requirements` | what must be true when this is done |
| `design.md` | `design` | how it works, and why it is shaped that way |
| `plan.md` | `plan` | the sequenced tasks (and this node's backlog) |
| `decisions.md` | `decisions` | choices made here that bind this node |

```bash
oj-helper resolve-path design --node [PROJECT_NODE]
oj-helper resolve-path plan   --node [PROJECT_NODE]/[SUBJECT]
```

## Nesting

A node holding more than one subject gets a subdirectory per subject, each with
its own typed files:

```
[PROJECT_NODE]/
  README.md
  requirements.md          # cross-subject requirements
  design.md               # cross-subject architecture
  plan.md                 # cross-subject sequencing (also this node's backlog)
  decisions.md
  [SUBJECT]/
    requirements.md
    design.md
    plan.md
    decisions.md
```

Nest when a file has stopped answering one question — not in advance. A node
that never needed a subject directory is a node that was the right size.

Every `plan.md` and `backlog.md` in the tree must be reachable by a pattern in
`backlog-glob=`. Anchor those patterns at the node, so an unanchored `**` does
not also pull in archived plans from a history area.

## Two filing rules that decide the ambiguous cases

**A review is not a design.** Point-in-time findings *about* existing work are
ephemeral and belong in a history area. `design.md` holds what the thing **is**
and **should be**. Filing genuine design content as a dated review buries it
somewhere nobody cites, and it stops being the answer to "what is the current
design?" while still being that answer. A document that does both gets split.

**A fact needs provenance.** Measurements go to `facts/` with a `MEASURED` /
`DERIVED` / `ASSERTED-UNVERIFIED` marker, not into `design.md` as a bare number.
See `../facts/README.md`.
